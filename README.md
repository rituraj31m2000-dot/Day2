**Intern:** Ritu Raj

**Program:** Veda Technology Internship — Day 2 of 45
**Tools Used:** Google Docs

## Objective
Understand the three core principles of information security — Confidentiality, Integrity, and Availability (CIA) — by analyzing real-world examples of each type of failure.

## Description
This project analyzes five real-world security incidents, each mapped to a failure of one of the three CIA Triad principles:

| Incident | Year | CIA Principle Violated |
|---|---|---|
| Equifax Data Breach | 2017 | Confidentiality |
| Stuxnet Worm | 2010 | Integrity |
| Bangladesh Bank Heist | 2016 | Integrity |
| Dyn DNS DDoS Attack | 2016 | Availability |
| WannaCry Ransomware | 2017 | Availability |

The full report, including incident details and interview question answers, is available in [`CIA_Triad_Analysis.md`](./CIA_Triad_Analysis.md).

## Approach
- Researched well-documented, publicly reported cybersecurity incidents
- Classified each incident according to which CIA principle it primarily violated
- Explained the reasoning behind each classification to reinforce understanding of the triad
- Compiled answers to the assigned interview questions (confidentiality, integrity, availability)

## Outcome
Completing this task clarified how the same category of technical failure (e.g., a DDoS attack or ransomware) maps cleanly onto a single leg of the CIA triad, and why comprehensive security strategies need to defend all three dimensions independently rather than treating "security" as one undifferentiated goal.

## Deliverables
- ✅ CIA Triad report
- ✅ Five real-world examples with analysis
